# Локальные артефакты

Каталог игнорируется Git (кроме этого файла). Здесь локально лежат выходы исследования:
curated-снимок `curated-all-sensors-exclude-2021-q2`, окна `alarm-spike-exclusions-v1`,
таблицы и метки `sensor-failure-v1/`, выходы версий `next-2026-09-27/` (v9, v11, разведка 5)
и плановые графики `maintenance-2026-planned/`. Команды, которые их строят, — в
[README исследования](../README.md).

В каждом выходе хранится manifest: SHA-256 входов и результатов, версии конфигураций,
меток и кода, Git revision и признак dirty. В Git публикуются только агрегированные
отчёты без идентификаторов (`../reports/`). Файла модели в продукте нет: прогноз — статичный
список, который пересчитывает worker через `packages/core`. MLflow служит журналом
экспериментов и не нужен для обслуживания запросов.
