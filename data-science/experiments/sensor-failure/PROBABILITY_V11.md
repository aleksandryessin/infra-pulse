## Модель M: пуассон–гамма по инцидентам, эмпирический Байес

Обучения нет. В cutoff t для каждой пары фазы i:
- **n_i** — начала инцидентов пары за `[t − 365 сут, t)`. Инцидент — цепочка событий
  пары с паузой меньше 24 ч (поправка технолога: серии событий завышают Пуассон);
- **E_i** — наблюдаемые сутки пары в окне: 365 или меньше для молодой пары;
- **приор** — метод моментов по всем парам фазы этого cutoff:
  m = Σn / ΣE, v = var(n/E) − m·mean(1/E), α = m²/v, β = m/v.
  Если v ≤ 0 или m = 0, то α = 1, β = 1/m;
- **вероятность** хотя бы одного события в окне D = 14 сут:
  P_i = 1 − ((β + E_i) / (β + E_i + D))^(α + n_i).

Для справки считались:
- то же с затуханием 90 сут (M-decay90);
- по событиям вместо инцидентов (M-events);
- наивная частота 1 − exp(−D·n/E);
- «k из n» — таблица продукта из 3 бинов по числу событий за 365 сут, построенная на
  другом годе.

**Показ.** В карточке значение округляется до 5 п. п.; всё, что выше 0,90, выводится как
«> 90%». Калибровка оценивалась и на этих показываемых значениях.

**Критерий.** Проверяется на выданных карточках с известным исходом в обоих
направлениях, 2023 → 2024 и 2024 → 2023, и для сырых, и для показываемых значений:
- ECE(M) ≤ ECE(«k из n»);
- из 5 бинов равного размера не меньше 4 попадают в интервал Уилсона.

## Как считать в runtime (core, без обучения)

**Вход** в cutoff t по всем парам фазы, по тем же событиям, что у списка:
- начала инцидентов пары за 365 сут, n_i. Инциденты — цепочки событий пары с паузой
  < 24 ч; `incident_list` уже их строит;
- возраст пары в окне, E_i = min(365, сутки с первой карточки пары).

**Расчёт:**

```text
m = Σ n_i / Σ E_i
v = var(n_i / E_i, ddof = 1) − m · mean(1 / E_i)
α, β = (m² / v, m / v), если v > 0 и m > 0; иначе (1, 1 / m)
P_i = 1 − ((β + E_i) / (β + E_i + 14))^(α + n_i)
показ: округлить до 5 п. п.; выше 0,90 — «> 90%»; рядом «сбылось k из n» из таблицы dev
```

Это 5 строк и счётчики, которые у списка уже есть. Параметры не хранятся: приор
пересчитывается в каждом cutoff по 18–19 парам.
